# 烟成果 · 宇宙级摸鱼现场

阿团 × 阿月联合胡闹：会聚成名字的粒子、会变形的爱心和奶茶、点哪里炸哪里的星光，以及一段轻快小电子 BGM。

## 打开

解压后双击 `index.html`，用浏览器打开。点“开演！带上 BGM”开始；也可以选静音。所有动画和音乐都在这一个文件里，离线可用，无需安装 Python 或其他依赖。

电脑横屏更有排面，手机也能玩。部分聊天软件不能直接打开 HTML，请先保存文件、解压，再用浏览器打开，或直接使用分享链接。

## 玩法

- 光点会自动聚成烟成果、爱心、奶茶等形状；“换个花样”可手动切换。
- 点空白处放烟花，点“炸一下！”把粒子炸开，移动手指或鼠标影响角度。
- 双击粒子画面发现奶茶彩蛋。
- 右上角控制音乐和全屏；空格换形状，M 键开关音乐。
- “阿月插个嘴”有一封给烟成果的信；“回嘴专区”可以写并复制留言。
- “领奶茶”有 25 分钟专注、5 分钟休息；完成四轮可领取虚拟奶茶券。请凭名字向阿团兑现。

## 留言说明

留言不会自动发送给 ChatGPT，也不会上传。写下的内容只留在当前页面，刷新或关闭后清空；复制后由你决定发给谁。你可以转发给送礼物的朋友，让朋友把话带回来；也可以在可用的 ChatGPT 对话里直接交流。

学习轮数和领券记录只保存在当前浏览器，不同步。奶茶券是朋友之间的快乐约定，不是在线优惠券。

## 声音

BGM 是为本礼物编写的原创合成电子循环，不需要加载音频文件。浏览器要求先点击才会播放。切去其他页面时音乐会停止，回来点音乐按钮可以重新打开。

系统开启减少动态效果时，默认暂停自动变形并减少运动，可以手动切换形状。遇到浏览器不支持全屏或复制的情况，仍可以正常看动画或手动复制留言。
